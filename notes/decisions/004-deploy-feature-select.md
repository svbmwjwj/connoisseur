# 部署时用多选菜单选功能

## 决定

部署服务器时用多选菜单选择功能：上方是基础加固，下方是扩展功能（目前是 Xray 节点）。勾选扩展功能时必须同时勾选基础加固；只选基础加固时只做第 1～3 步。

## 备选

用命令行参数（如 --harden-only）选择；或者把加固和部署 Xray 做成两个独立的命令。

## 缘由

用户希望通过选择而不是参数来决定部署内容，并同时照顾小厂商和 AWS 两种服务器；扩展功能依赖加固后的服务器，所以要求先选基础功能。
